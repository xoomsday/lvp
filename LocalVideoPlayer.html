Keyboard Shortcuts

Playlist View

  • o - Open file chooser
  • s - Save selected files
  • x - Remove selected videos
  • v - Play focused video
  • ↑ / ↓ - Move focus
  • Shift+↑ / ↓ - Extend selection
  • Ctrl+↑ / ↓ - Move selection
  • Space - Toggle selection
  • Ctrl+a - Select all
  • Escape - Clear selection

Video Player View

  • Space - Play / Pause
  • ← / → - Seek
  • ↑ / ↓ - Volume
  • m - Mute / Unmute
  • l - Toggle loop
  • r - Add section mark
  • Shift+r - Delete section mark
  • n / p - Next / Previous video
  • Shift+n / p - Next / Prev mark
  • [ / ] - Adjust speed
  • = - Reset speed
  • a - Toggle aspect ratio
  • f - Toggle fullscreen
  • . - Show/hide info
  • q - Back to playlist

Press ? in any view to show or hide this help.
